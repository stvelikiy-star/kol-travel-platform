# ALCOHOL COMPLIANCE SPEC

## Назначение

Alcohol module в KÖL — юридически чувствительный и полностью отключаемый модуль для будущей работы с алкогольной категорией. Этот документ является продуктовой и технической спецификацией, а не юридической консультацией и не даёт юридических гарантий.

`ALCOHOL_MODULE_ENABLED=false` by default. Модуль нельзя включать, рекламировать, использовать в checkout, доставке, платежах или партнёрском кабинете до юридической проверки и отдельного разрешения.

## Базовые правила

- Модуль OFF by default.
- Включается только после юридической проверки.
- Должен существовать глобальный выключатель alcohol module.
- Должен существовать отдельный выключатель по партнёру.
- Alcohol routes должны быть gated.
- Alcohol products скрыты, если модуль выключен.
- Alcohol orders нельзя завершить без `age_check_passed`.
- Любые alcohol flows должны логироваться.
- Никаких юридических гарантий платформа не даёт.

## Доступ клиента

Требования:
- age gate 18+ перед входом в alcohol category;
- авторизация клиента;
- проверка возраста клиента;
- сохранение результата проверки возраста только в рамках разрешённой политики данных;
- повторная проверка при checkout;
- юридическое предупреждение перед оформлением заказа.

Ограничения:
- гость не может оформлять alcohol order;
- клиент без age verification не может видеть/оформлять alcohol products;
- при `ALCOHOL_MODULE_ENABLED=false` клиент не видит alcohol products и не может попасть в alcohol checkout.

## Доставка и получение

Требования:
- проверка возраста при получении заказа;
- курьер или ответственное лицо должно отметить `age_check_passed`;
- заказ нельзя перевести в `completed` без `age_check_passed`;
- при провале проверки используется статус `age_check_failed`;
- нужна процедура возврата/отмены по правилам платформы и закона.

## Партнёр и лицензии

Требования:
- alcohol partner доступен только если юридически разрешено;
- партнёр должен предоставить действующие лицензии;
- админ проверяет документы до публикации;
- `license_status` должен быть `approved`;
- у партнёра должен быть включён отдельный alcohol flag;
- истекшая, отозванная или неподтверждённая лицензия блокирует alcohol products.

## Временные ограничения

Требования:
- configurable sale window, например 09:00–22:00, если закон это допускает;
- checkout должен проверять окно продаж;
- вне разрешённого времени alcohol products недоступны к заказу;
- время должно учитывать локальный timezone и график партнёра.

## Реклама и контент

Запрещено:
- агрессивная реклама алкоголя;
- баннеры алкоголя на главной без юридического разрешения;
- смешивание алкоголя с семейным, детским, школьным, спортивным или wellness-контентом;
- продвижение alcohol category через общие скидки без compliance approval;
- alcohol promos до юридической проверки.

Обязательно:
- юридическое предупреждение;
- маркировка 18+;
- нейтральная подача без стимулирования чрезмерного употребления.

## API и данные

Alcohol routes:
- gated;
- disabled by default;
- возвращают `ALCOHOL_MODULE_DISABLED`, если модуль выключен;
- проверяют global flag, age verification, partner license, partner alcohol flag, sale window, stop status.

Сущности:
- `AlcoholProduct`;
- `PartnerBusiness.license_status`;
- `PartnerBusiness.alcohol_enabled`;
- `User.age_verified`;
- `Delivery.age_check_passed`;
- `Order(type=alcohol)`;
- `AdminLog`;
- `SystemLog`.

## Что нужно проверить с юристом перед запуском

- Можно ли дистанционно продавать алкоголь на территории Кыргызской Республики.
- Можно ли доставлять алкоголь курьером.
- Какие лицензии нужны партнёрам и оператору платформы.
- Можно ли платформе быть marketplace-посредником для alcohol category.
- Какие часы продажи допустимы.
- Какие требования к age verification до checkout.
- Какие требования к проверке возраста при получении.
- Какие документы курьер должен проверять.
- Нужно ли хранить факт проверки возраста и как долго.
- Какие предупреждения обязательны на странице и в checkout.
- Разрешены ли скидки, промокоды и loyalty для alcohol category.
- Разрешена ли реклама alcohol products.
- Какие ограничения на смешивание alcohol content с family/kids content.
- Какие правила возврата при failed age check.
- Какие штрафы и ответственность несут партнёр, оператор платформы и курьер.

## Решение Stage 01D

Alcohol module остаётся выключенным. `ALCOHOL_MODULE_ENABLED=false`. Любая реализация alcohol flows переносится на отдельный stage после юридической проверки.
