# MVP ROADMAP

## Stage 01A — Basic Project Docs

Цель: создать базовую документацию и структуру проекта.

Результат: README, env example, gitignore, project brief, структура платформы, роли пользователей и roadmap.

## Stage 01B — Cabinets and Flows Docs

Цель: описать кабинеты и ключевые пользовательские сценарии.

Результат: документация по клиентскому, партнерскому, административному и операционному flow.

## Stage 01C — Database and API Docs

Цель: спроектировать данные и API-контракты.

Результат: схема сущностей, связи, статусы, API endpoints и правила доступа.

## Stage 01D — Compliance and Onboarding Docs

Цель: описать юридические, операционные и партнерские требования.

Результат: onboarding партнеров, compliance checklist, правила модерации и ограничения.

## Stage 02 — Design System

Цель: подготовить визуальную и интерфейсную основу.

Результат: дизайн-система, токены, компоненты, состояния и правила UI.

## Stage 03 — Public Homepage + Catalog

Цель: создать публичную главную страницу и каталог.

Результат: базовый публичный опыт поиска и просмотра предложений.

## Stage 04 — Detail Pages

Цель: создать страницы деталей услуг, предложений и партнеров.

Результат: карточки с описанием, условиями, доступностью и входом в заказ.

## Stage 05 — Cart + Checkout + Booking

Цель: реализовать корзину, оформление заказа и бронирование.

Результат: клиент может собрать заказ, указать данные и отправить заявку.

## Stage 06 — Client Cabinet

Цель: создать клиентский кабинет.

Результат: профиль, заказы, бронирования, история и поддержка.

## Stage 07 — Partner Cabinet

Цель: создать партнерский кабинет.

Результат: управление профилем партнера, услугами, заявками и статусами.

## Stage 08 — Admin Panel

Цель: создать административную панель.

Результат: управление каталогом, пользователями, партнерами, заказами и настройками.

## Stage 09 — Notifications + Telegram

Цель: подключить уведомления и Telegram-каналы.

Результат: системные уведомления для клиентов, партнеров и операторов.

## Stage 10 — Payments

Цель: подключить платежную логику.

Результат: платежи, статусы оплаты, комиссии и базовая финансовая отчетность.

## Stage 11 — Loyalty + Promos

Цель: добавить удержание клиентов и промо-механику.

Результат: промокоды, бонусы, скидки и правила применения.

## Stage 12 — Alcohol Compliance Module

Цель: подготовить отдельный compliance-модуль для alcohol category только после юридического разрешения.

Результат: возрастные проверки, ограничения, правила выдачи и контроль включения модуля.

## Stage 13 — Production Build + Deployment

Цель: подготовить production-сборку и деплой.

Результат: рабочая production-версия, окружения, проверки и базовый мониторинг.

## Stage 14 — Real Partner Onboarding

Цель: начать подключение реальных партнеров.

Результат: заполненные партнерские профили, реальные предложения и операционные правила.

## Stage 15 — Mobile App Future

Цель: подготовить направление мобильного приложения.

Результат: требования, сценарии и архитектурные решения для будущего mobile app.
